# LPのタイトル： カケトコ mini ver0.3 MySQL

## 制作LPの説明（40文字程度）
    - 「カケトコ」は農家のための農薬検索・ECサイトです。農家目線から見て、わかりやすい、検索しやすいサイトを作ろうとしています。
  
## 工夫した点・こだわった点
    - さくらのサーバーにDBを作り、そこから情報を取り出しています。
    - EC機能はShopifyのAPIを持ってきてます。
    - 大元は農水省の農薬情報のExcelで、そこからいらない情報を削ぎ落としてCSVに加工してインポートしました。

## 次回トライしたいこと（または機能）
    - 元データが10万行ぐらいあるうちの7000行ぐらいをとりあえず入れています。本来はこれを加工せずに丸ごとインポートして、それでも機能させられるプログラムを作りたいです。
    - まだ殺虫剤30種類しか入っていないので、殺菌剤、除草剤と増やしていきたいです。
    - 殺虫剤と殺菌剤と除草剤では結果画面に表示したい内容が変わってくるので、それぞれでコードを組み直さなきゃいけないことが分かりました。
    - 「カケトコスコア」というそれぞれの農薬の点数をつけたいと思っていますが、点数の計算の仕方（アルゴリズム？）の考え方が分かりません。自分の頭の中にある順番通りにならないので、ここを深掘りして勉強していきたいです。

## 備考（感想、シェアしたいこと等なんでも）
    - 自分の頭の中にあった「こんなのがあればいいのに…！」が少しずつ形になってきているので、めちゃくちゃ楽しいです！
    - 実際に作り出すと、「こんなの」の細かい部分があやふやだと作れない、「なんか違う…」ってなることに気づいてきました。自分の中でまずしっかり細部まで言語化することが大事だと思いました。
